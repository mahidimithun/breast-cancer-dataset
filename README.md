# Breast Cancer Diagnostic Classification using Support Vector Machines (SVM)

## 📊 Dataset & Source
This project utilizes the **Breast Cancer Wisconsin (Diagnostic) Dataset** to classify breast masses as either benign or malignant based on geometric features computed from a digitized image of a fine needle aspirate (FNA).

🔗 **Dataset Link:** [Kaggle - Breast Cancer Dataset](https://www.kaggle.com/datasets/yasserh/breast-cancer-dataset)

---

## 🛠️ Code Workflow & Implementation Steps

The Python pipeline is executed sequentially to transform raw medical metrics into reliable predictive outputs:

1. **Exploratory Data Analysis (EDA):** Evaluated data shapes, distributions, and collinear relationships across 30 clinical features using `Seaborn` and `Matplotlib`.
2. **Target Variable Encoding:** Cleaned the text-based target column (`diagnosis`) by mapping categorical labels `'B'` (Benign) to `0` and `'M'` (Malignant) to `1` to align with standard clinical conventions.
3. **Stratified Train-Test Split:** Divided the dataset into training ($80\%$) and testing ($20\%$) subsets. Employed `stratify=y` to ensure that class proportions remained perfectly identical across both splits.
4. **Feature Standardization:** Initialized a `StandardScaler` to fit strictly on the training data and transform both sets. This eliminates scale discrepancies among variables (like area vs. smoothness) that would otherwise distort the SVM's hyperplane.
5. **Model Training:** Configured and trained a **Support Vector Machine (SVM)** classifier using a Radial Basis Function (RBF) kernel to manage non-linear decision spaces.
6. **Performance Assessment:** Extracted predictions using `X_test_scaled` and compiled a full metric suite including accuracy scoring, a detailed classification report, and an interactive confusion matrix display.

## 2. Classification Performance Metrics Explained

To fully evaluate a medical diagnostic model, looking at overall accuracy is not enough. We must break down how the model handles individual classes using **Precision**, **Recall**, and **F1-Score**. 

Below is the explanation of the classification report metrics generated by the SVM model:

### 📑 Metric Definitions

* **Precision (Positive Predictive Value):** Out of all the instances the model *predicted* as a certain class, how many were actually correct?
  * **Class 0 (Benign): 0.96** $\rightarrow$ When the model predicts a tumor is benign, it is correct 96% of the time.
  * **Class 1 (Malignant): 0.97** $\rightarrow$ When the model flags a tumor as malignant, it has a 97% confidence rate (only a 3% false alarm rate).

* **Recall (Sensitivity / True Positive Rate):** Out of all the *actual* real-world cases of a certain class, how many did the model successfully catch?
  * **Class 0 (Benign): 0.99** $\rightarrow$ The model successfully identified 99% of all actual benign tumors.
  * **Class 1 (Malignant): 0.93** $\rightarrow$ **The most critical clinical metric.** The model successfully detected 93% of all actual cancer cases. While strong, the remaining 7% represent critical False Negatives that require minimization in diagnostic deployment.

* **F1-Score:** The harmonic mean of Precision and Recall. It provides a single balanced metric that rewards models for having both high precision and high recall simultaneously.
  * **Class 0:** 0.97
  * **Class 1:** 0.95

---

### 🧮 Understanding the Global Averages

At the bottom of the classification report, three global averages summarize system performance:

1. **Accuracy (0.96 / 96.49%):** The overall percentage of correct predictions out of the total test pool ($110$ correct predictions out of $114$ test samples).
2. **Macro Average (0.96):** Calculates the metrics for each class independently and takes their unweighted mean. This treats both classes with equal importance, proving the model is highly stable for both tumor types.
3. **Weighted Average (0.96):** Calculates the metrics by factoring in the true structural volume (**Support**) of each class (72 Benign vs. 42 Malignant). The fact that the macro and weighted averages match perfectly shows that our stratified class distribution kept the model entirely balanced and unbiased.
